# empreinte-externe : journal des versions

## 0.1.0

- Première version : relevé d'identité d'une entreprise française dans le site, le registre de l'État, Pappers, LinkedIn, Wikidata, Wikipedia et la fiche Google.
- Tableau des faits, écarts à corriger classés, homonymes, limites du relevé.
- Option « réponses IA » : rapprocher les erreurs d'une IA des écarts qui les expliquent.
- Entreprise hors de France : relevé partiel, annoncé comme tel.
- Sortie dans la conversation, ou dans un fichier Markdown sur demande.
