# Contribuer

Merci de votre intérêt pour ces skills.

## Ce qui est bienvenu

- **Les retours d'usage.** Vous avez testé un skill sur un vrai cas ? Racontez-nous ce qui a marché et ce qui a coincé, avec le modèle « Retour d'usage » des issues. C'est la contribution la plus utile.
- **Les signalements de bugs**, avec le modèle « Bug ».
- **Les pull requests de correction** : coquille, lien cassé, instruction ambiguë, bug dans un script.

## Ce que nous n'acceptons pas

- **Les nouveaux skills** et les changements de méthode. Ces skills reflètent la façon dont nous travaillons, et nous tenons à leur cohérence. Si vous avez une idée, ouvrez plutôt une issue pour en discuter.

## Licence des contributions

En proposant une contribution, vous acceptez qu'elle soit publiée sous la licence du dépôt : CC BY 4.0 pour les textes, MIT pour les scripts.

## Organisation du dépôt

- Une famille de skills = un plugin, dans `plugins/<famille>/`.
- Chaque skill vit dans `plugins/<famille>/skills/<nom-du-skill>/`, avec son `SKILL.md` et son `CHANGELOG.md`.
- Les noms de skills sont en minuscules, avec des tirets.
